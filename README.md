# Cuisine Classification – Cognifyz Technologies

## Project Overview
This project was completed as part of the Machine Learning Internship at Cognifyz Technologies.

The objective is to build a machine learning classification model that predicts the cuisine category of a restaurant using available restaurant-related features.

## Task Objectives
- Understand and preprocess the restaurant dataset.
- Handle missing values and encode categorical features.
- Split the dataset into training and testing sets.
- Train machine learning classification models.
- Evaluate model performance using accuracy, precision, and recall.
- Analyze cuisine-wise classification performance.

## Dataset
- Dataset: `cognifyz_restaurant_rating_dataset.csv`
- Number of records: 1,000
- Number of columns: 9
- Cuisine categories: 10

## Models Used
- Logistic Regression
- Random Forest Classifier

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- Confusion Matrix
- Cuisine-wise performance analysis

## Tools and Technologies
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Project Files
- `Cognifyz_Task_3_Cuisine_Classification (1).ipynb` – Jupyter Notebook containing the project implementation.

## Conclusion
This project demonstrates the application of machine learning classification techniques to restaurant cuisine prediction and explores the challenges of classifying multiple cuisine categories.
